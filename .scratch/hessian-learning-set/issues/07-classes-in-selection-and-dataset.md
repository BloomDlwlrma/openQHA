# 07: Classes in the selection and the Dataset (`01_select.py`, `dataset.py`, `04_dataset.py`)

**What to build:** `dataset.select` reads `draw.dat` when it exists under the Dataset folder: every drawn molecule is a row of `select.dat`, with its `classes`, and with `has_basins` / `has_frames` false until branch A / 02 have run -- so the campaign's progress is one table and `hl_labels.slurm --name` always sees the whole draw. `dataset.build` gains the PRODUCTION split (round-5 Q4, user ruling: by frame): `--split-by frame` -- every labelled frame of a non-pinned molecule is drawn into train / valid / test at 90 / 5 / 5 with a per-frame seeded draw (`_rng(seed, "frame", qm9_index, generator, basin, k)`, so a frame's split never depends on what else is labelled); the pinned seven stay a whole-molecule test set (assumption, see round 5); previous `index.dat` decisions kept as now; the molecule-level split of ticket 04 stays as `--split-by molecule` for the smoke set. `index.dat` gains a `classes` column; the Record gains a `[[Class]]` table (molecules, frames, per split, labelled, unlabelled) and `04_dataset.py` prints it. The MACE form: every split file also carries `REF_energy` (info), `REF_forces` (arrays) and, where the frame has one (round-5 Q7 (b): basin / merged / saddle frames), `REF_hessian` (info, flattened) with `has_hessian = true/false` -- MACE-torch's default keys, so `--energy_key`/`--forces_key` need no override and 05_train reads `REF_hessian` where present and masks the Hessian term otherwise -- plus a `split` key; and one merged `mace_<name>.<level>.extxyz` (all splits in one file, the user's "single xyz") beside the per-split files and the OpenREACT HDF5.

**Blocked by:** 05 (the draw); 04 (done).

**Delivers:** `index.dat` with classes; a held-out set per class.

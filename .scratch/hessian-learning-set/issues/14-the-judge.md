**What to build:** Algorithm 3, the ruler, reading only shipped paths: `judge.run(root, tag, name, level, engine_name, base_engine="mace-off23_medium", spice_test=None)`. Per held-out frame with a Label (the `test` split of the Dataset, plus `valid` reported separately): `H_theta` by `MACECalculator.get_hessian` (full matrix, `create_graph=False`), then `hessian_compare.compare_hessians(H_theta, H_r, masses, positions)` -- HIP families 1-4, `D_ii` vs `lambda_r` per reference mode, `MIXING`, the noise floors, `NOISE_FLOOR_MAX_CM` from basin frames -- and the same for the base engine; rows aggregated per structure class (from `index.dat`'s `classes`) and per distribution: `interpolation` (the by-frame test of the drawn molecules), `out_of_molecule` (the pinned seven, whole molecules), `in_distribution` (the four shipped molecules among the seven), with the low-mode (`omega_r < 300 cm^-1`) frequency MAE, the full-spectrum MAE, `||A||_F^2 / n_vib` (eq. 1, the loss's own quantity, exact), and the base model's numbers beside each. Thermochemistry at the model's OWN minima for the seven (round-2 Q13 (a)): the msRRHO pipeline (`s0_thermo_msrrho.py` with `S0_ENGINE=<fine-tuned>`, `--policy crest_native`) gives `S_msRRHO`, `MODEL_ERROR_S_REF`, `OMEGA_ENGINE_OWN_CM` matched to reference modes by block overlap, written beside `D_ii`; the `[Anharmonic]` block (round-2 Q6 (a), assumed): a reference mode with `omega_r < 30 cm^-1` or a `mode_curvature` FD self-check `> 5 cm^-1` where a profile exists is set aside from the entropy tier and listed with the 1-D level count (oxetane: fundamental 52.92 cm^-1 is the experimental check). Forgetting (round-2 Q7): E and F RMSE of the fine-tuned and the base model on a FIXED 5,000-frame draw of the SPICE test split (`data/training_sets/spice_test_5000.extxyz`, drawn once by seed from the on-disk SPICE HDF5 through `training_set.py`, its frame ids committed), the ratio to the base reported. Thresholds (round-2 Q8, assumed as stated in the spec): `PASS` / `FAIL` per line -- held-out low-mode MAE below the in-distribution 8.5 cm^-1; abs(`MODEL_ERROR_S_REF`) <= 0.2 cal/mol/K excluding `[Anharmonic]` modes; no in-distribution HIP metric worse than the base by > 15 %; SPICE E/F within 15 % of the base; every threshold stated with the grid floor of the Label (S0-C-44) as its lower bound. Two calibration engines make the judge falsifiable: `--engine base` must PASS the no-degradation lines and show 0 on `||A||_F^2` against `H_r := H_base` (must-pass); `--engine base --scale 0.9` (a wrapper engine returning `0.9 F` and `0.81 H`, `openqha/engine` `ScaledEngine`) must FAIL the low-mode line (must-fail). Writes `<root>/<tag>/_datasets/<name>/judge/<run>/judge.{out,toml,dat}` (`judge.dat`: one row per frame; the `.toml`: `[[Class]]`, `[[Distribution]]`, `[Thermochemistry]`, `[Anharmonic]`, `[Forgetting]`, `[Verdict]`) and `06_judge.py --tag --name --level --engine <name|base> [--scale] [--run]` prints the tables.

# 17: The curated QM9 archive as one HDF5, extracted on demand (`data/curated_qm9.py`, `scripts/tooling/s0_pack_curated_qm9.py`)

**Why (2026-09-21):** the first branch A gate on tianhe failed on all 16 molecules -- `reference geometry not found ... curatedQM9 at None`: `data/qm9/` is not in git and the 133 661-file directory lives on the workstation. The user ruled: one `.db` or `.hdf5` instead of moving 133 661 files. HDF5, because an ASE `.db` stores Atoms and loses QM9's frequency line, both SMILES and both InChI (F7 and `qm9_smiles_from_xyz` read them); the archive stores every file's TEXT unchanged.

**What to build:** `s0_pack_curated_qm9.py` -- `curated_qm9._index()` (the repairs winning over the originals as the directory lookup decides), every file's bytes concatenated into a gzip-chunked `blob` (uint8) with `offset` (int64, N+1), `index` (int32, ascending) and `pattern` (int8, the PATTERNS position); attrs: source, N, census per pattern, sha256 of all the text, date; `--verify N` reads N random molecules back byte for byte. `curated_qm9`: `H5_NAME`, `archive(cfg)` (`S0_CURATED_QM9_H5` > `data.curated_qm9_h5` > `data/qm9/curated_qm9.h5`), `Archive` (index / pattern / offset in memory, `text(n)`, `filename(n)`, `extract(n)` atomic into `_h5cache/` beside the archive), `open_archive` (once per process), `find()` falls back to the archive when the directory has no entry, `available()` / `census()` see it (`form = hdf5`). `config.qm9_xyz()` untouched: it reaches the archive through `find()`. Iterating all of QM9 (`training_set.qm9_targets`, the census) still needs the directory (documented).

**Blocked by:** nothing. **Unblocks:** the campaign's branch A on tianhe.

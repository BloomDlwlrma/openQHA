# 05: Structure classes and the draw (`openqha/data/structure_classes.py`, `configs/structure_classes.yaml`, `00_draw.py`)

**What to build:** `configs/structure_classes.yaml` -- one entry per class: name, SMARTS (or a ring rule: `min_rings`, `min_fused`, `aromatic_rings`, `ring_size`), a note, and the QM9 count you quoted where known (round-5 Q2). `structure_classes.classify(smiles) -> set of class names` (RDKit: SMARTS matches; ring rules on `GetRingInfo`); `census(smiles_iter) -> counts per class`. `00_draw.py --name <dataset> --per-class 500 --seed S [--classes configs/structure_classes.yaml] [--exclude-training]`: reads `data/training_sets/qm9_targets_membership.dat`, drops `in_training = true` (Q5 (a)), classifies every remaining molecule, draws 500 per class with one seeded generator over the sorted candidates -- the UNION across classes (Q1 (a)); a class with fewer than 500 candidates takes them all and the shortfall is a row of the Record (Q1 (c)); the pinned seven are added as rows (always in); writes `<root>/<tag>/_datasets/<name>/draw.{out,toml,dat}` -- `draw.dat`: qm9_index, smiles, n_heavy, classes (';'-joined), in_training; the Record: per class the QM9 census count, the candidates outside SPICE, the number drawn, the shortfall; the union size. `scripts/tooling/s0_structure_census.py`: the census over all 133,885 QM9 SMILES against the quoted counts; a pattern off by more than 10 % is flagged as suspect (Q2 (a)).

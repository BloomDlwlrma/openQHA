# 29: Continuous chirality for g' with the `procrustes` library

**What to build:** `procrustes` (pip `qc-procrustes`; Meng et al., Comput. Phys. Commun. 2022, 276, 108334; BibTeX key `meng2022procrustes` in `docs/cite/cite_openQHA.bib`) added to the `openqha` environment and recorded in the environment docs. In `conformer_search/degeneracy.py`: the mirror-pair test reports `RMSD_ROT = sqrt(rotational(a, b, translate=True, scale=False).error / N)` and `RMSD_ORTHO` from `orthogonal(...)`; a pair is a mirror pair iff RMSD_ORTHO < 0.75 RTHR and RMSD_ROT >= 0.75 RTHR (same numbers as CREST's `intraconfRMSD`, inputs unchanged: rotamer file + `cre_members`, rotor atoms excluded). A conformer's achirality becomes `MIRROR_SELF_RMSD`: the minimum over permutations within its RDKit equivalence classes of the rotational-Procrustes RMSD between its core and its own reflection; achiral iff below 0.75 RTHR; threshold and value in the record. `symmetry_class` (point-group label) stays as a diagnostic column in the Report and decides nothing. Permutation enumeration is ours (the library has none); above 10^4 candidates the value is `unresolved` and g' falls back to the label rule with `G_PRIME_SOURCE = label_fallback`. `kabsch_rmsd` is kept and asserted equal to the library's rotational RMSD on every pair it sees. Property schema: `MIRROR_SELF_RMSD`, `RMSD_ROT`, `RMSD_ORTHO` per conformer, `CHIRALITY_THRESHOLD` in the header. Tormat is not adopted until its reference is read.

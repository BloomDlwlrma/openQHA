# 30: Is the molecule in MACE-OFF23's training set? Step 1, the shipped species

**What to build:** a `training_set_membership` module (`openqha/data/training_set.py`) that answers, for one SMILES, whether the molecule is in the released MACE-OFF23 training data (Apollo repository doi:10.17863/CAM.107498, the SPICE-derived `train_large_neut_no_bad_clean.xyz` and `test_large_neut_all.xyz` under `hessian-train/SPICE`; path declared in `configs/openqha.yaml` as `training_sets.mace_off23.root`), and if so with how many conformers, in which file (train / test) and under which `config_type`. Membership by canonical identity, not string match: the file's `smiles` are atom-mapped with explicit hydrogens; both sides go through RDKit -- strip atom maps, remove explicit H, canonical SMILES -- and are compared at three strictnesses, each recorded: (a) isomeric canonical SMILES, (b) canonical SMILES with stereo removed, (c) InChIKey connectivity block. The index of the 1.0 M frames (canonical key -> frames, file, config_type) is built once and cached as `data/training_sets/mace-off23_spice_index.parquet` (with the two source files' sizes and mtimes recorded, rebuilt when they change), so a query is a lookup. Step 1 runs it on the species declared in `configs/edges_testset.yaml` (the four shipped molecules first, then every declared species) and writes the answer into the molecule's `levels/level_compare.toml` as `[Training_Set]` (SOURCE = "mace-off23_spice", IN_TRAINING = true/false, MATCH_LEVEL = isomeric / no_stereo / connectivity / none, N_TRAIN_FRAMES, N_TEST_FRAMES, CONFIG_TYPES, N_HEAVY_ATOMS) and the Report states in one line whether the tiers are in-distribution numbers. `s0_thermo_msrrho.py --step compare` fills the block when the index exists; absent index -> the block is absent and the Report says the check was not run (never a silent false). Records: also a repo-level table `data/training_sets/shipped_species_membership.dat` (one row per declared species) for the SI.

**Blocked by:** nothing (reads files that exist).

# 27: `hessian_compare` at the reference geometry, and `level_compare` on every quantity

**What to build:** a `hessian_compare` Calculation (`openqha/thermochem/hessian_compare.py`) that, for every MACE basin the merge map marks `kept`, evaluates the MACE Hessian **at the reference geometry** (`$atoms` of `orca/<level>/basinNN/job.hess`, via `hessian.hessian(atoms, calc, mode="analytic")`, stored as the engine file `mace/basinNN/hessian_at_<level>.npy`) and compares it with the reference `$hessian`. Both go through `project_and_diagonalise`; ORCA's `$vibrational_frequencies` stay the round-trip check of the reference side (< 0.5 cm^-1). Compared per basin: relative Frobenius error and eigenvalue MAE in the mass-weighted Eckart-projected basis; modes paired by `quasi_harmonic.mode_match.match` (block-overlap gate, collisions counted, no Hungarian) with frequency MAE / max over all modes and over modes < 300 cm^-1, lowest mode each side, N_COLLISIONS, MIN_BLOCK_OVERLAP; the `crest`-preset per-mode T*S table on both spectra and the summed low-mode T*S difference. Thermochemistry is compared **at each level's own geometry** only: the two levels' `[[Basin]]` rows side by side (E_REL, ZPE, H_THERMAL, S_VIB, S_ROT, G_I, POPULATION), paired by the merge map, and `[Ensemble]` / `[Result]` terms (S_REF, S_CONF_PRIME, DS_BAR, H_CONF, CP_CONF, S_ABS, G_TOTAL, max |dp_i|). `$dipole_derivatives` compared only where both engines have them; MACE-OFF23 has no charges: `DIPOLE_DERIVATIVES_PRESENT = false`. Records `levels/hessian_compare.out/.toml` with `[Calculation_Info]` (ENGINE_LEVEL, REFERENCE_LEVEL, GEOMETRY = "reference", PRESET, N_BASINS_COMPARED, DIPOLE_DERIVATIVES_PRESENT), `[[Basin]]`, `[Ensemble]`. `level_compare` grows: `[[Level]]` adds S_REF, DS_BAR, H_CONF, CP_CONF, N_BASINS_90; `[Tiers]` adds MODEL_ERROR_ for each ensemble term; the Report prints the per-basin table. `s0_thermo_msrrho.py --step hessian_compare`.
